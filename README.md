# 麻将记分

家里打麻将用的小型计分应用。Flask + SQLite + 一个手机友好的网页界面。开服后局域网里所有人用浏览器打开就能看，记录会一直存着。

## 计分规则

- **自摸**：赢家选；金额从 `2 / 4 / 6 / 8 / 10 / 12 / 14` 块里选；其他三家各付该金额
- **插杠**：杠的人选；其他三家各付 `1`
- **暗杠**：杠的人选；其他三家各付 `2`
- **杠别人**：杠的人选 + 给杠的人选；给杠的人付 `3`
- **黄庄**：流局，不计分

## 运行

```bash
pip install -r requirements.txt
python3 app.py
```

启动后会打印类似 `http://192.168.x.x:5000` 的局域网地址，家里别的设备打开就能用。`PORT` 环境变量可改端口。

数据保存在 `data/mahjong.db`（SQLite）。
